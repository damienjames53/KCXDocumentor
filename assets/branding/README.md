# Branding Assets

Reusable keycentrix visual assets for presentation generation.

## Company Name Hard Rule

`keycentrix` in all lowercase is the only accurate representation of the company name in visible content, generated artifacts, documentation, templates, scripts, defaults, speaker notes, and metadata.

Use capitalized variants only when preserving an existing exact file path, external source title, legal entity text, or historical quote that cannot be changed without breaking traceability.

## Images

- `images/keycentrix-full-logo.png`: compact full logo from root assets.
- `images/keycentrix-template-logo.png`: large transparent logo.
- `images/sticky-logo.png`: small transparent logo.
- `images/keycentrix-logo-from-template.png`: logo extracted from the keycentrix template and used by newer generated decks.

Use `presentation_lib.brand.LOGOS` instead of hard-coding these paths in new scripts.
